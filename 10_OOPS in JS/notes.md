# javascript and classes

- Javascript is a prototype language 

- JavaScript has classes since ES6 (ECMAScript 2015). Classes in JavaScript are basically a way to create blueprints for objects, just like in other programming languages like Java or Python.

- JavaScript classes are just syntactic sugar over prototype-based inheritance. Internally, JavaScript still uses prototypes, but classes make the code cleaner and easier to understand
